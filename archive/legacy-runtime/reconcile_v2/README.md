# Topology V2 Viewer

Standalone 3D viewer for `topology-v2.json` and optional `topology-v2.qa.json`.

## Open It

From repo root:

```bash
python3 -m http.server 8765
```

Then open:

- `http://localhost:8765/reconcile_v2/viewer.html`

You can either:

1. Load files via the file inputs in the left panel, or
2. Pass URLs directly:

```text
http://localhost:8765/reconcile_v2/viewer.html?data=/tmp/topology-v2.json&qa=/tmp/topology-v2.qa.json
```

## What It Shows

- Pascal-inspired full-model material pass:
  - warm plaster-like structure
  - neutral slab floors
  - wood-toned doors
  - glass windows
- Story filtering and room selection via sidebar
- Topology overlays:
  - `ADJACENT_TO` lines
  - gap regions/lines from `Gap` nodes
  - optional boundary overlays
- Pipeline stage toggles similar to the original viewer interaction model

## Notes

- The viewer expects the V2 structure generated by `python -m reconcile.cli_v2`.
- Wall thickness is a geometric proxy based on room-boundary gaps, not structural assembly truth.
